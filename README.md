# SqwarkSelf releases

Downloads and the update feed for **SqwarkSelf**, the Mac focus guard. macOS 14 (Sonoma) or later, Apple silicon and Intel.

**[Download the latest release](https://github.com/sqwark-industries/sqwarkself-releases/releases/latest)**

- `appcast.xml` is the feed the app checks for updates: `https://raw.githubusercontent.com/sqwark-industries/sqwarkself-releases/main/appcast.xml`
- Each release has `SqwarkSelf-<version>.dmg` and its `.sha256`. Every DMG holds an app signed with Sqwark Industries' Developer ID
  and notarised by Apple, and every update carries a signature the app checks against a key baked into it.

The source is private; this repo holds only the builds and the feed. Copyright © 2026 Sqwark Industries LLC.
